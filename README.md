# ⚡ PSKP | Engineering & Risk Tech Portfolio (Frontend Client)

A high-performance, strictly monochromatic web portfolio showcasing projects at the intersection of **Computer Science Engineering**, **AI Systems Architecture**, **Verifiable Inference**, and **Financial Risk Advisory**. 

---

## ⚙️ System Architecture: Decoupled Application

This project utilizes a modern, decoupled architecture to separate the user interface from the data processing logic. 

*    **Frontend Client (This Repository):** Built with React and Tailwind CSS, focusing on an accessibility-first, high-contrast UI. 
*    **Backend Services:** The API, financial logic, and AI risk models are maintained in a separate service. 
    *   👉 **[View the Backend API Repository Here](https://github.com/Pskp6769/flask-url-shortener)**
